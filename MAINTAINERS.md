# 维护者 / Maintainers

| Maintainer | Role |
| --- | --- |
| YukiRyou (`yoshino-xiao7`) | Repository owner, release approval, security coordination |

至少一名维护者必须审查涉及认证、凭据、网络目标、图片边界、重试、工具副作用或发布工作流的变更。仓库增长后，应增加第二名具有 release/security 权限的维护者，并在此文件记录职责，而不是把关键知识留在私人聊天中。

At least one maintainer must review changes involving auth, credentials, network targets, image boundaries, retries, tool side effects, or release workflows. As the project grows, add a second maintainer with release/security responsibility and record ownership here rather than leaving critical knowledge in private chat.
