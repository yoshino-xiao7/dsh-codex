## 中文

### 变更

- 新增当前会话回复详略（低、中、高），所选值从下一次 Codex 请求起生效。
- 新增当前会话推理摘要（自动、简洁、详细、关闭），不把摘要形式伪装成推理强度。
- 模型设置通过独立的本机 loopback-only 只读 RPC 获取 Host 安全能力投影，并与 Harness 通用目录合并展示输入模态、上下文、最大输出、当前安装 provider catalog 实际提供的推理档位与 Fast 支持；RPC 不可用或能力未知时不推断。
- OAuth 授权提示支持分别复制登录链接和验证码，只有用户点击时才写入剪贴板，不记录短期授权材料。
- 额度页在进入、页面重新可见或窗口重置节点到达时主动刷新，不进行后台轮询；每周窗口进入不足 24 小时时只在本地切换为精确时间。
- 重新登录开始时清除旧账号额度；显式传输切换会清除当前精确会话的 WebSocket→SSE 回退锁存，自动模式已选中但仍处于回退时也可执行“恢复自动”。
- 设置页展示 Host 严格解析的套餐类型，不从余额或模型推断套餐。
- `/codex-usage refresh` 立即读取真实账号额度，`status` 只读取进程内最近请求观测；两者都不发送模型请求。
- 连接诊断支持复制只含固定状态与受限事实的脱敏报告。
- 会话请求设置展示请求、连接复用、增量上下文与 SSE 回退等脱敏传输健康状态。
- 账号诊断把 HTTP 失败固定区分为 401/403 鉴权、429 限流、5xx 服务端和其他 HTTP 错误，不暴露原始状态文案或响应体。

### 兼容性

- 精确兼容目标仍为 DeepSeek Harness `0.1.1-rc.2`、pi-ai `0.82.1` 与 Node.js `>=22.19.0 <25`。
- Fast、transport、回复详略和推理摘要均为当前进程、当前会话偏好；重启后恢复安全默认值。
- 本草稿尚未发布；Linux、macOS、Windows CI/profile smoke、本版本候选提交、维护者批准与 13 项真实账号验收均待完成。`0.0.4` 的历史证据不继承到 `1.0.0`。
- 诊断与传输健康只公开严格脱敏的进程内事实，不执行主动模型请求，也不能替代真实对话验收。

## English

### Changes

- Current sessions now expose reply verbosity (low, medium, or high), effective on the next Codex request.
- Current sessions now expose reasoning-summary style (auto, concise, detailed, or off) without presenting summary form as reasoning effort.
- Model settings obtain the Host's safe capability projection through an independent local loopback-only read-only RPC, merge it with Harness's generic catalog, and display input modalities, context, maximum output, reasoning efforts exposed by the installed provider catalog, and Fast support. Unavailable or unknown capabilities are not inferred.
- OAuth prompts can copy the sign-in link and verification code separately. Clipboard writes require an explicit user click and short-lived authorization material is not logged.
- Usage refreshes when settings opens, the page becomes visible, or a window reset boundary is reached, without background polling. Crossing the weekly under-24-hour threshold changes only the local exact-time display.
- Re-authorization clears usage from the previous account. Explicit transport changes clear the exact conversation's WebSocket-to-SSE fallback latch, and **Reset to Auto** remains actionable when Auto is selected but fallback is still active.
- Settings shows the Host's strictly parsed plan type without inferring a plan from balance or models.
- `/codex-usage refresh` performs an immediate real account-usage read, while `status` reads only the process-local recent-request observation; neither sends a model request.
- Connection diagnostics can copy a sanitized report containing only fixed statuses and bounded facts.
- Conversation request settings expose sanitized transport health for requests, connection reuse, delta context, and SSE fallbacks.
- Account diagnostics map HTTP failures to fixed 401/403 authentication, 429 rate-limit, 5xx server, and other HTTP categories without exposing raw status messages or bodies.

### Compatibility

- The exact targets remain DeepSeek Harness `0.1.1-rc.2`, pi-ai `0.82.1`, and Node.js `>=22.19.0 <25`.
- Fast, transport, reply verbosity, and reasoning summary are current-process, current-session preferences and return to safe defaults after restart.
- This draft is unpublished. Linux, macOS, and Windows CI/profile smoke, the accepted candidate commit, maintainer approval, and all 13 live-account checks for this version remain pending. Historical `0.0.4` evidence is not inherited by `1.0.0`.
- Diagnostics and transport health expose only strictly sanitized process-local facts, send no active model request, and do not replace live conversation acceptance.
