## 中文

### 变更

- 兼容新版 Harness 的 typed remote 模型发现与设置写入接口，同时保留旧版连接接口兼容路径，恢复 Codex 模型列表、选择与保存。
- 兼容新版 Harness 设置服务，修复旧具名导出移除后插件无法启动的问题。
- 将内部额度组名称 `gpt-reserve` 显示为“使用限额重置”，英文显示为 “Usage limit reset”。

### 兼容性

- 冻结兼容目标仍为 DeepSeek Harness `0.1.1-rc.2`、pi-ai `0.84.4` 与 Node.js `>=22.19.0 <25`；新增兼容层同时覆盖当前 Harness 的 typed remote/settings 合同，但不据此声称所有未来预发布版本均兼容。
- 本版本不改变 OAuth、请求参数、传输、Fast、额度读取或故障恢复语义。
- 发布前必须重新完成 Linux、macOS、Windows CI/profile smoke `3/3` 并绑定本版本候选；真实账号验收从独立的 `1.1.3` 记录以 `0/13` 开始，不继承旧版本结论。

### 验收记录

## English

### Changes

- Support the newer Harness typed-remote model discovery and settings mutation APIs while retaining the legacy connection path, restoring Codex model listing, selection, and persistence.
- Support the newer Harness settings service, fixing plugin startup after removal of the legacy named exports.
- Display the internal `gpt-reserve` quota group as “Usage limit reset” (and “使用限额重置” in Chinese).

### Compatibility

- The frozen compatibility targets remain DeepSeek Harness `0.1.1-rc.2`, pi-ai `0.84.4`, and Node.js `>=22.19.0 <25`. The compatibility layer also covers the current typed remote/settings contracts without claiming compatibility with every future prerelease.
- This release does not change OAuth, request parameters, transports, Fast, usage reads, or recovery semantics.
- Linux, macOS, and Windows CI/profile smoke must be rerun at `3/3` and bound to this candidate before publication. Live-account validation starts independently at `0/13` for `1.1.3` and inherits no older result.

### Acceptance record

- [`v1.1.3.acceptance.json`](v1.1.3.acceptance.json) is the independent acceptance record for this version. Platform evidence and maintainer approval are bound before publication, while post-release live validation continues from `0/13`.

### Artifact verification

- SHA-256: generated by the protected release workflow and attached to the GitHub Release.
- SRI: generated by the protected release workflow, read back from the Registry, and attached to the GitHub Release.
