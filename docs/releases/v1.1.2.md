## English

### Changes

- Update Cordis `4.0.2`, Schemastery `3.18.2`, pi-ai `0.84.4`, and TypeScript `7.0.2`, while explicitly pinning the include, loader, and native-module loading dependencies required by the Harness runtime.
- Enable strict peer-dependency installation checks so incompatible runtime combinations fail during build and CI.
- Add at most three bounded retries for npm audit 429, 5xx, DNS, and network-timeout failures when building a release candidate, with a per-attempt time limit. Real vulnerabilities fail immediately, and exhausted retries remain fail-closed.

### Compatibility

- The exact targets are DeepSeek Harness `0.1.1-rc.2`, pi-ai `0.84.4`, and Node.js `>=22.19.0 <25`.
- This release does not change OAuth, the model catalog, usage reads, transport selection, Fast, the request-parameter contract, or existing recovery semantics.
- This document describes an unpublished candidate. Linux, macOS, and Windows CI/profile smoke, maintainer approval, and supply-chain evidence are recorded independently for `1.1.2` and inherit no older conclusion. Post-release live-account validation starts at `0/13`.

### Acceptance record

- [`v1.1.2.acceptance.json`](v1.1.2.acceptance.json) is the independent draft for this version. New platform evidence will be bound after the candidate commit is fixed.

### Artifact verification

- SHA-256: pending generation by the protected release workflow.
- SRI: pending generation by the protected release workflow and Registry readback.
