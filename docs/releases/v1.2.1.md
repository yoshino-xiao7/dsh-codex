## English

### Changes

- Statically inject `remote.llm` and `remote.settings` into the Web client and use the Harness `0.1.2-rc.1` typed-remote model discovery and settings mutation APIs while retaining the legacy connection fallback.
- Parse both the newer direct `RemoteResult` and legacy nested results, restoring Codex model listing, selection, and persistence.
- Display the internal `gpt-reserve` quota group as “Usage limit reset” (and “使用限额重置” in Chinese).

### Compatibility

- The exact targets are DeepSeek Harness `0.1.2-rc.1`, pi-ai `0.84.4`, and Node.js `>=22.19.0 <25`.
- This release does not change OAuth, request parameters, transports, Fast, usage reads, or recovery semantics.
- Linux, macOS, and Windows CI/profile smoke must be rerun at `3/3` and bound to this candidate before publication. Live-account validation starts independently at `0/13` for `1.2.1` and inherits no older result.

### Acceptance record

- [`v1.2.1.acceptance.json`](v1.2.1.acceptance.json) is the independent acceptance record for this version. Platform evidence and maintainer approval are bound before publication, while post-release live validation continues from `0/13`.

### Artifact verification

- SHA-256: generated by the protected release workflow and attached to the GitHub Release.
- SRI: generated by the protected release workflow, read back from the Registry, and attached to the GitHub Release.
