## 中文

### 变更

- 模型选择器左侧新增独立传输按钮，用图形菜单为当前会话选择自动、SSE、WebSocket 或 WebSocket 缓存，并支持完整键盘操作、恢复自动和中英文提示。
- 设置页新增默认折叠的“连接诊断”。本机检查完全离线；账号检查只读取现有额度并在必要时刷新 OAuth。两者均不会发送 Codex 模型请求或消耗模型额度。
- Host 以一个不可变、安全投影的能力接口统一提供目录字段、推理档位和 Fast 支持；Web 客户端不再维护 Fast 模型硬编码副本。
- 诊断报告只包含固定检查 ID、状态码及受限事实，不向浏览器暴露凭据、account ID、原始响应、请求头或原始错误。

### 兼容性

- 精确兼容目标保持为 DeepSeek Harness `0.1.1-rc.2` 与 Node.js `>=22.19.0 <25`；不承诺兼容其他 DSH 预发布版本。
- Fast 与 transport 仍是当前进程、当前会话偏好；切换从下一次请求生效，重启后恢复 Fast 关闭与传输自动。
- 本版本不加入主动模型请求诊断，因此诊断结果不能替代真实文本、reasoning、图片、工具、Fast 或各传输方式的账号网络验收。
- 本文档是开发草稿；候选提交、三平台验收、制品摘要和维护者批准仍为 `TBD`，不得据此发布。

## English

### Changes

- A dedicated transport button beside the model selector provides a graphical current-conversation menu for Auto, SSE, WebSocket, or cached WebSocket, with complete keyboard behavior, reset-to-Auto, and bilingual copy.
- Settings now has collapsed connection diagnostics. The local check is fully offline; the account check only reads existing usage and refreshes OAuth when necessary. Neither sends a Codex model request nor consumes model usage.
- One immutable, safely projected Host capability interface now supplies catalog fields, reasoning levels, and Fast support. The Web client no longer maintains a duplicate hard-coded Fast model list.
- Diagnostic reports contain only fixed check IDs, status codes, and bounded facts. Credentials, account IDs, raw responses, headers, and raw errors never reach the browser.

### Compatibility

- The exact compatibility target remains DeepSeek Harness `0.1.1-rc.2` with Node.js `>=22.19.0 <25`; compatibility with other DSH prereleases is not claimed.
- Fast and transport remain current-process, current-conversation preferences. Changes apply to the next request, and restart restores Fast off and transport Auto.
- This version does not add an active model-request diagnostic, so diagnostics do not replace live account acceptance for text, reasoning, images, tools, Fast, or individual transports.
- These notes are a development draft. Candidate commit, three-platform acceptance, artifact digests, and maintainer approval remain `TBD`; this draft is not publishable.
